# 热档片间（Hotbay）

影院素材分区温层：登记 → 冷热迁移 → 保留销毁 → 目录互证。

- 前端 http://127.0.0.1:6300
- API http://127.0.0.1:11300
- `docker compose up -d --build`

## 保留策略挂载架构（全局唯一口径）

本系统在两种可行架构中**只贯彻「以挂片库间为准」**，不与键名单方案混用：

- **挂载听片库间**：每条保留策略绑定唯一 `vault_id`（片库间）。
- **执行只扫该间**：扫描谓词固定为
  `vault_id = 挂间 AND status='在册' AND 片龄(营业日 − 发行日) >= max_age_days`，
  他间任何分区都不进入候选，**甲间策略不可能扫穿乙间**；同间未到期或迁移占坑分区跳过。
- **作用域恒为「整间」**：`retention_batches.scope` 与 `destroy_runs.scope` 均落 `整间`，
  批次 `predicate` 字段保存可重放的挂载谓词，`/api/保留重放/{batch_id}` 可重放命中集合并对账。
- **不支持显式分区键名单挂载**：保留相关请求体 `extra='forbid'`，出现键名单字段直接 422 拒绝。
- **片龄口径唯一**：`片龄 = 营业日(settings) − 发行日`，由 `services.core.partition_age` 统一计算，
  扫描、预览、重放、前端分区册共用。

### 终态与并发闭合

- 每次扫描生成一条 `retention_batches`，终态仅 `已完成 / 已中断`；进程中断留下的 `扫描中`
  在启动时由 `db._migrate_legacy` 回收为 `已中断`，不留不可解释终态。
- 保留扫描与冷热迁移共用库级写锁（`BEGIN IMMEDIATE`），串行提交；
  扫描对存在 `执行中` 迁移单（占坑）的分区一律跳过，杜绝「已迁又毁」。
- 同库存在 `扫描中` 批次时拒绝发起新扫描（409）。
- 策略配置入口、扫描入口、策略表、分区册、销毁流水（含作用域列）、待销毁徽章、总览同刷联动。

> 范围限定：仅覆盖挂载层与片龄作用域。跨间改挂、宽限时序不在本期范围。
